Checks: required fields and types, ISO date, currency code, non-negative amounts, quantity × unit price = amount, line items sum to subtotal, subtotal + tax = total (tolerance 0.01). Rules mirror src/selfcorrect/invoices/rules.py; the JavaScript port is a convenience copy, so the Python package stays the reference implementation.
